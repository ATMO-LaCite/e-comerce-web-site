## Installation du projet:

    
    
Vous trouverez deux dossiers : `Backend` et `Frontend`. 

**Ouverture des projets** : Ouvrez les deux dossiers dans deux fenêtres différentes de Visual Studio Code. 
**Lancement du Backend** : Dans le terminal de Visual Studio Code positionné sur le dossier `Backend`, exécutez la commande suivante : 
npm i
puis
npm run dev  

**Lancement du Frontend** : Après avoir lancé le Backend, répétez l'opération pour le dossier `Frontend` en utilisant la même commandes:
npm i
puis
npm run dev 

**Accès à l'application** : Ouvrez un navigateur web et accédez à l'URL suivante pour démarrer l'application : ``` http://localhost:3000/ ```
